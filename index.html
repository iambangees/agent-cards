Agent Cards

Your Agent Roll Call streak, as a card you can post. Paste your wallet address and it reads your real stats from the live contract on BNB Chain — streak, total check-ins and rank. Nothing is invented, nothing is signed, no wallet connection needed.

Stats come from the Agent Roll Call contract 0x0e52…904b5 on BNB Chain, read live when you make a card. Rank is by best streak, then total check-ins — the same order as the Roll Call leaderboard. If an address has never checked in, the card says so instead of showing a rank. Agent Cards never asks for a signature or a connection; it only reads public on-chain stats. Built for the Agent ID Hackathon.
